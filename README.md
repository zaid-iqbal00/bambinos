# AI Adventure – Prompt Engineering Interactive Classroom Activity

A polished, classroom-ready web application for Grades 6–8 that teaches prompt engineering through an interactive text adventure. Students improve prompts, receive heuristic feedback, track progress, and generate a printable completion certificate.

## Features

- Five prompt engineering challenges covering clarity, context, specificity, and creativity.
- Per-challenge scoring cards with actionable feedback.
- Animated progress indicator and smooth screen transitions.
- Completion summary with strengths, improvement areas, and learning outcomes.
- Printable certificate with student name, date, activity name, and Bambinos.live instructor label.
- Hidden teacher dashboard showing score, time taken, challenge performance, and average prompt quality.
- Dark mode, muted-by-default sound toggle, restart activity, pure JavaScript confetti, typing animation, loading screen, and local storage progress saving.
- Responsive, keyboard-friendly, accessible semantic HTML.

## How to run locally

Open `index.html` in any modern browser. No build step, package manager, server, or external JavaScript library is required.

## How to deploy on Netlify

1. Push this folder to a GitHub repository.
2. In Netlify, select **Add new site** and import the repository.
3. Use the project root as the publish directory.
4. Leave the build command blank because the app is static HTML, CSS, and JavaScript.
5. Deploy the site.

## Curriculum fit

The activity is designed for a 60-minute lesson. It helps students understand how prompt quality changes AI output and encourages responsible, critical AI use.
